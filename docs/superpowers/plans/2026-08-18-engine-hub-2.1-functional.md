# MilyVoice Engine Hub 2.1 Functional Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convertir Engine Hub 2.1 de arquitectura registrada a producto utilizable: selección automática segura bajo 2 GiB, un carril EN→ES ultrarrápido real, fallbacks completos, Tutor/temas/voces en extensión y gates CI/NSIS.

**Architecture:** MilyVoice conserva `Faster-Whisper + M2M100` como baseline de calidad y añade proveedores opcionales detrás de `provider_factory.py`. `ModelAdvisor` solo podrá seleccionar packs cuyo runtime y archivos estén completos; `ResourceGovernor` bloquea combinaciones que excedan memoria. Para equipos débiles, el primer carril promocionable es Moonshine Streaming EN + Marian Tiny INT8; sherpa-onnx y whisper.cpp quedan disponibles únicamente cuando su runtime/pack sea verificable y no se anuncian como activos antes de pasar benchmark.

**Tech Stack:** Python 3.13 privado, FastAPI/WebSocket, CTranslate2, Moonshine Voice, sherpa-onnx, Faster-Whisper, Rust/Tauri, Chromium Manifest V3, GitHub Actions.

**Spec:** `MASTER.md`

## Global Constraints

- `main` permanece estable; todo desarrollo ocurre en `pruebas`.
- Presupuesto duro del proceso MilyVoice: 2048 MiB.
- Objetivo Lite estable: <= 1200 MiB; pico <= 1536 MiB; Rescue <= 700 MiB.
- VRAM de equipos mínimos: no obligatoria; presupuesto MilyVoice <= 384 MiB.
- Solo un ASR y un MT cargados simultáneamente.
- Audio/transcripción/MT/TTS local salvo proveedor cloud autorizado explícitamente.
- EN/ES/ZH son Tier 1; EN→ES y ZH→ES mantienen prioridad de recepción realtime.
- Ningún motor opcional puede ser seleccionado si su runtime/modelo no está realmente listo.
- Los modelos no comerciales no se promocionan como predeterminados.
