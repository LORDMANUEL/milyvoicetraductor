# Política de seguridad

## Datos que no deben publicarse

No se deben subir al repositorio, issues o pull requests:

- contraseñas, tokens, claves API o certificados privados;
- audio o transcripciones de reuniones reales;
- correos, teléfonos o identificadores personales;
- archivos de configuración reales del usuario;
- bases de datos, logs o cachés generados por una instalación real.

## Reporte responsable

Si descubres una vulnerabilidad, evita publicar una prueba que exponga información de terceros. Describe el comportamiento, versión afectada y pasos mínimos de reproducción usando datos sintéticos.

## Diseño local

MilyVoiceTraductor se diseña para procesar voz localmente. La Fase 1 no implementa telemetría ni envío de contenido a servicios externos.
