# Changelog

Todos los cambios relevantes de MilyVoiceTraductor se documentan aquí.

## [0.1.0] - 2026-08-17

### Añadido
- Fundación Tauri 2 + Rust + Svelte/TypeScript.
- Servicios modulares de configuración, SQLite, logs, caché y diagnóstico.
- Contratos para motor IA y gestor de modelos con estados reales no instalados.
- Panel y páginas de administración de Fase 1.
- Landing page estática para GitHub Pages.
- CI, controles de privacidad y documentación inicial.
