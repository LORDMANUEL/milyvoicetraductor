MilyVoiceTraductor

Una aplicación para escuchar, transcribir y traducir.

Desktop, extensión Chromium, motor de IA, audio de Windows y herramientas de sesión trabajan como un solo producto, sin configuración manual de Python, puertos ni tokens.

01

Reuniones en tiempo real

Traduce Teams Desktop, Teams Web y otras reuniones reproducidas desde una pestaña o desde el audio del sistema.

02

Audio universal

Utiliza pestañas Chromium, micrófono, archivos multimedia y WASAPI loopback para escuchar lo que realmente necesitas.

03

Subtítulos y voz

Muestra subtítulos, distingue hablantes, reproduce la traducción con TTS y ofrece modos de aprendizaje, video y karaoke.

04

Instalación autónoma

Incluye runtime Python privado, motor local, bridge Native Messaging y reparación integrada para Windows x64.

MilyCompute

El hardware se adapta al trabajo, no al revés.

MilyCompute examina CPU, memoria y aceleradores disponibles. La CPU siempre permanece lista y NVIDIA CUDA se utiliza únicamente cuando el modelo puede ejecutarse de forma compatible y medible.

Privacidad

La conversación permanece en tu equipo.

Reconocimiento, traducción, TTS y sesiones trabajan en localhost. Solo la preparación inicial de los modelos requiere conexión a Internet.

✓

Sin telemetría.
No se analizan ni envían conversaciones a un servicio de métricas.

✓

Persistencia opcional.
Las sesiones se guardan únicamente cuando el usuario lo habilita.

✓

Enlace local protegido.
Desktop y extensión se comunican mediante Native Messaging y credenciales efímeras.
