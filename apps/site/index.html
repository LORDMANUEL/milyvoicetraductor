Procesamiento local
Producto

Una plataforma, componentes independientes.

La aplicación, el motor IA, la extensión y los modelos tienen ciclos separados para poder actualizar cada pieza sin romper las demás.

01

Escritorio ligero

Tauri 2 + Rust para usar el WebView nativo del sistema y mantener bajo el consumo.

02

Motor local

Python se ejecuta como motor desacoplado y puede instalarse como runtime aislado o sidecar compilado.

03

Extensión Chromium

Captura explícita de audio de pestaña en Chrome, Edge y Chromium, con permisos mínimos y conexión localhost autenticada.

04

Modelos versionados

Descarga a staging, activación atómica, versiones y rollback independientes del ejecutable principal.

Privacidad

El contenido de la reunión no es material de diagnóstico.

La arquitectura separa los datos operativos del contenido. Los logs se sanitizan antes de escribirse, no hay telemetría y las transcripciones solo persisten si el usuario lo habilita.

✓

Sin tracking.
La web tampoco usa analytics, píxeles o cookies de seguimiento.

✓

Logs sanitizados.
Tokens, correos y directorios personales comunes se redactan.

✓

Permisos progresivos.
La captura de pestaña requiere una acción explícita del usuario; el micrófono permanece opcional y desactivado por defecto.
