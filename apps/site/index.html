Procesamiento local
Producto

Una forma simple de seguir conversaciones globales.

Instala la aplicación, carga la extensión en tu navegador y traduce el audio de tu reunión a español sin enviar el contenido a un servicio de traducción externo.

01

Instalación guiada

El instalador Windows prepara el motor local y el entorno necesario para comenzar.

02

IA en tu equipo

Reconocimiento y traducción se ejecutan localmente, con CPU como base y aceleración opcional.

03

Subtítulos en Chromium

Chrome, Edge, Brave y Chromium pueden mostrar la traducción del audio de la pestaña activa.

04

Modelos administrados

La aplicación descarga, verifica y administra el modelo recomendado sin incluir pesos gigantes dentro del instalador.

Privacidad

Tu reunión no debería convertirse en telemetría.

El motor trabaja localmente. Los logs se sanitizan, no hay tracking y las transcripciones solo se guardan cuando el usuario decide habilitarlo.

✓

Sin tracking.
La aplicación y la web no usan analytics, píxeles ni telemetría del contenido.

✓

Sin audio persistente por defecto.
El contenido no se almacena como requisito para traducir.

✓

Permisos progresivos.
La captura de pestaña comienza únicamente después de una acción explícita del usuario.
