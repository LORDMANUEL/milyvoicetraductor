Privacidad

La conversación permanece en tu equipo.

Reconocimiento, traducción, TTS y sesiones trabajan en localhost. Las sesiones se guardan únicamente cuando el usuario lo habilita.

✓

Sin telemetría de conversaciones.
El contenido de audio y texto no se usa como métrica.

✓

Persistencia opcional.
El usuario controla si guarda sesiones.

✓

Enlace local protegido.
Desktop y extensión usan Native Messaging y credenciales efímeras.
