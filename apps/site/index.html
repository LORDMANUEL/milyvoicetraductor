MilyVoiceTraductor

Una aplicación para escuchar, transcribir y traducir.

Desktop, extensión Chromium, runtime privado y audio de Windows trabajan como un solo producto sin configurar Python, puertos ni tokens manualmente.

01

Reuniones en tiempo real

Teams Desktop, Teams Web y otras reuniones reproducidas desde una pestaña o desde el audio del sistema.

02

Audio universal

Pestañas Chromium, micrófono, archivos multimedia y WASAPI loopback.

03

Subtítulos y voz

Subtítulos, hablantes, TTS y modos de reunión, aprendizaje, video y karaoke.

04

Instalación autónoma

Runtime privado, Native Messaging, diagnóstico y reparación para Windows x64. Los modelos no se descargan durante la instalación: se eligen después dentro de MilyVoice.

Privacidad

La conversación permanece en tu equipo.

Reconocimiento, traducción, TTS y sesiones trabajan en localhost. Las sesiones se guardan únicamente cuando el usuario lo habilita.

✓

✓

Enlace local protegido.
