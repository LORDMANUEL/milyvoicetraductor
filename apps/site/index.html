Procesamiento local
Producto

Instala dos piezas. El resto se configura solo.

Instala MilyVoiceTraductor y añade la extensión Chromium. El bridge local las enlaza automáticamente y la aplicación prepara el modelo recomendado durante el primer inicio.

01

Runtime incluido

Python 3.13 y las dependencias del motor viajan dentro del instalador. No necesitas winget, Python del sistema ni pip durante la instalación.

02

Autoreconocimiento

App y extensión se descubren por Native Messaging local. Sin token que copiar y sin puerto que escribir.

03

Modelo Tiempo Real INT8

Whisper Small y M2M100 se descargan desde Hugging Face; la app convierte M2M100 a INT8 y muestra cada fase sin abrir consolas externas.

04

IA en tu equipo

Reconocimiento y traducción se ejecutan localmente, con CPU como base y aceleración GPU opcional.

Privacidad

Tu reunión no debería convertirse en telemetría.

El motor trabaja en localhost. Los logs se sanitizan, no hay tracking y las transcripciones solo se guardan cuando tú lo decides.

✓

Sin tracking.
La aplicación y la web no usan analytics, píxeles ni telemetría del contenido.

✓

Sin audio persistente por defecto.
El contenido no se almacena como requisito para traducir.

✓

Credencial efímera.
La extensión autorizada recibe acceso local temporal; no guarda un token permanente.
